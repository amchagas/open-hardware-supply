# Codebook

Based on the [Open-O-Meter](https://doi.org/10.1016/j.procir.2018.08.306), tagged as [OoM], with a few noted additions, tagged as [New]. The Open-o-Meter makes a distinction between “product openness”, tagged as [Pd], and “process openness”, tagged as [Pc].

## OSH compatible license [Pd] [OoM]
Information contents are published under respectively relevant
open-source-compatible licenses. That is, the documentation types of hardware
components are released under an OSH-compatible license (e.g. TAPR) and the
eventual software components are released under an OSS-compatible license (e.g
GPL)

## Design files [Pd] [OoM]
The design files of all product components designed by the originator (all
technology types included) are made publicly available. When there are software
components, source code is available, when there are electronic hardware
components, ECAD files are available and when there are non-electronic hardware
components CAD files are available.

## Bill of materials [Pd] [OoM]
A bill of material is available.

## Assembly instructions [Pd] [OoM]
Assembly instructions are available.

## Original files [Pd] [OoM]
All files, including design files, bill of materials, and assembly instructions,
are released in their original format.

## Open access [Pd] [New]
The academic works describing the hardware are published in Open Access.

## Version control system [Pc] [OoM]
All files are maintained in a version control system allowing interested people
to edit the files.

## Contribution guide [Pc] [OoM]
Guidance is provided to external people on how to contribute to the product
development.

## Issue tracking system [Pc] [OoM]
An issue tracking or equivalent system allows tracing tasks and improvement
propositions.

## Community space [Pc] [New]
Authors engage and promote community discussion concerning the project in an appropriate space such as a forum or mailing list.
